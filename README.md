# Undertomes LC Conditions

[![Foundry](https://img.shields.io/badge/Foundry_VTT-14-5b3a70?style=for-the-badge)](https://foundryvtt.com/)
[![System](https://img.shields.io/badge/system-D%26D_5e-8b2635?style=for-the-badge)](https://github.com/foundryvtt/dnd5e)

**Undertomes LC Conditions** brings The Undertomes' LC inspired statuses to Foundry VTT with automatic resolution. And an added effect to have them visualized in a style similar to the titular game.

## Requirements

- **Foundry VTT Version 14**
- **D&D5e Version 6.0 or greater**

## Installation

### Install from a URL

1. In Foundry’s setup screen, open **Add-on Modules → Install Module**.
2. Paste this into **Manifest URL**:

```text
https://raw.githubusercontent.com/twofelled/undertomes-foundry-module/main/module.json
```

3. Click **Install**, then enable **Undertomes LC Conditions** in your world under **Manage Modules**.

### Manual installation

1. [Download the source ZIP](https://github.com/twofelled/undertomes-foundry-module/archive/refs/heads/main.zip) and extract it.
2. Place the extracted folder in `Data/modules/` and name it `undertomes-limbus`, with `module.json` directly inside.
3. Restart Foundry and enable the module under **Manage Modules**.

## Usage

Select a token and open **LC Status Manager** to manage its statuses.
On attacks and spells, use the activity’s **LC Conditions** tab to configure status application and other effects.
